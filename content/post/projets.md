- Langage : Javascript.
- Description : SIOTradeLink est une extension conçue pour simplifier vos recherches du jeu boursier. Elle vous redirige les actions du site Planspiel Börse vers Boursorama pour une analyse plus complète de cette action.

### ThinkPHP
- Langage : PHP, HTML.
- Description : ThinkPHP est un projet de quiz en connexion avec une base de données. Il permet de créer des quiz, de les modifier et de les supprimer. Il est également possible de répondre à un quiz et d'afficher les résultats.

- Dépot : [Lien vers le dépôt](https://github.com/KLenesley/ThinkPHP)
